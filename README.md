# NBA בוקר

דף אישי בעברית שבונה את עצמו מחדש: תוצאות הלילה, שחקן הלילה, טבלת הליגה, חדשות חשובות ומשחקי הלילה עם סיכויי ניצחון.

## מה יש בדף

1. **כותרת**: "בוקר NBA | יום/חודש", מספר המשחקים ושעת העדכון.
2. **שחקן הלילה**: מי שקלע הכי הרבה נקודות (בשוויון מכריעים האסיסטים, ואחריהם הריבאונדים). כולל תמונה, נתונים, אחוזי קליעה וממוצעי עונה.
3. **תוצאות אמש**: המשחק של שחקן הלילה מופיע ראשון. בכל משחק הקבוצה המנצחת למעלה ושני הקלעים המובילים מכל קבוצה.
4. **טופ 10 מהלכים** מיוטיוב.
5. **טבלת הליגה**: מזרח ומערב, פלייאוף (ירוק), פליי-אין (צהוב) ומחוץ לפלייאוף (אדום).
6. **חדשות**: עד 5 חדשות משמעותיות מ-24 השעות האחרונות, מתורגמות לעברית. חדשה מ-3 השעות האחרונות מקבלת פס "Breaking" בראש הדף.
7. **הלילה ב-NBA**: שעת פתיחה בשעון ישראל וסיכויי ניצחון לפי יחסי ההימורים.

## מקורות מידע

| מקור | מה מביא | צריך מפתח? |
| --- | --- | --- |
| ESPN | תוצאות, נתוני שחקנים, טבלה, חדשות, יחסי הימורים | לא |
| MyMemory | תרגום החדשות לעברית | לא |
| YouTube Data API | קישור ישיר לתקצירים ולטופ 10 | כן, לא חובה |
| The Odds API | גיבוי ליחסי ההימורים | כן, לא חובה |

גם בלי אף מפתח הדף עובד: במקום קישור ישיר לסרטון מופיע כפתור "חיפוש ביוטיוב".

## הרצה במחשב

פעם ראשונה בלבד:

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

בניית הדף:

```bash
.venv/bin/python build.py
```

הדף נשמר בתיקייה `site/`.

ניסיון בלי לשמור כלום (הדף נשמר בתיקייה `preview/`):

```bash
.venv/bin/python build.py --dry-run
```

הצגת לילה מסוים (התאריך לפי שעון ארה"ב):

```bash
.venv/bin/python build.py --dry-run --date 2026-11-14
```

## מפתחות (לא חובה)

יוצרים בתיקייה קובץ בשם `.env` עם השורות הבאות:

```
YOUTUBE_API_KEY=המפתח-שלך
ODDS_API_KEY=המפתח-שלך
```

הקובץ `.env` לא עולה ל-GitHub. בענן המפתחות נשמרים כ-GitHub Secrets.

## בענן (GitHub)

- **כתובת הדף:** https://hadarfr222.github.io/nba-daily/
- **המאגר:** https://github.com/hadarfr222/nba-daily
- **תזמון:** הקובץ `.github/workflows/build.yml` מריץ את `build.py` על שרתי GitHub ב-08:00 ובערך ב-23:00 (שעון ישראל), וגם כל 3 שעות לרענון החדשות. זה רץ גם כשהמחשב כבוי.
- **הרצה ידנית:** במאגר נכנסים ללשונית Actions, בוחרים "NBA page" ולוחצים Run workflow.
- **מפתחות:** במאגר נכנסים ל-Settings, משם ל-Secrets and variables, ואז Actions. השמות: `YOUTUBE_API_KEY`, `ODDS_API_KEY`.
- **ארכיון:** בכל ריצה נשמרים הדף והזיכרון (`site/`, `state/`) בחזרה למאגר, כך שהימים הקודמים לא נמחקים.

## מבנה הקבצים

| קובץ | תפקיד |
| --- | --- |
| `build.py` | נקודת הכניסה: אוסף נתונים ובונה את הדף |
| `nba/data.py` | איסוף כל החלקים. אם חלק נכשל מדלגים עליו והשאר נבנה |
| `nba/espn.py` | הפניות ל-ESPN |
| `nba/videos.py` | חיפוש ביוטיוב, עם זיכרון (cache) ומגבלה יומית |
| `nba/odds.py` | חישוב סיכויי ניצחון מיחסי ההימורים |
| `nba/translate.py` | תרגום לעברית |
| `nba/teams.py` | שמות 30 הקבוצות בעברית |
| `nba/render.py` | בניית ה-HTML |
| `static/style.css` | העיצוב |
| `state/` | זיכרון בין ריצות: סרטונים שכבר נמצאו ותרגומים |
